# COWRIE - HONEYPOT #

**Cowrie Honeypot** is a cybersecurity monitoring project that emulates SSH and Telnet services to detect and log malicious activity. The honeypot records brute-force login attempts, executed commands, file downloads, and attacker behavior without exposing a real system. This project demonstrates practical experience with threat detection, Linux administration, log analysis, and network security monitoring.

## Features ##
🍯 Emulates SSH and Telnet services\
🔐 Captures brute-force login attempts\
📋 Records attacker commands and sessions\
📂 Logs malware downloads and file transfers\
📊 Generates security logs for analysis\
🐧 Runs on Linux environments\
🛡️ Safe environment for studying cyber attacks\
